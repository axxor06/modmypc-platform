# 🖥️ ModMyPC

> **A modern full-stack computer store and PC customization platform built with PHP & MySQL.**

ModMyPC is a complete web application designed for computer enthusiasts, gamers, students, and professionals who want to purchase PC components, build custom computers, compare products, and request repair or upgrade services—all from a single platform.

The project combines an intuitive user experience with a powerful backend, making it suitable as both an e-commerce and service management system.


🚀Live **Website:** https://modmypc.com/

---

## ✨ Features

### 👤 User Features
- Secure user registration and login
- Google Sign-In integration
- Email verification & OTP authentication

- View saved/custom PC builds

- Browse computer components

# 🚀 Installation

## 1. Clone Repository

```bash
git clone https://github.com/yourusername/modmypc-php.git
````

---

## 2. Move Project

Copy the project into your web server directory.

### XAMPP

```
htdocs/
```

### WAMP

```
www/
```

### LAMP

```
/var/www/html/
```

---

## 3. Import Database

Import

```
sql/migration.sql
```

into MySQL using phpMyAdmin or MySQL CLI.

---

## 4. Configure Database

Update your database credentials in the PHP configuration file.

Example:

```php
$host = "localhost";
$user = "root";
$password = "";
$database = "modmypc";
```

---

## 5. Run

Start

* Apache
* MySQL

Open

```
http://localhost/modmypc
```
